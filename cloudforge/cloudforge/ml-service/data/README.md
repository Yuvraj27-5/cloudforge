# data

**Phase 7.**

Two clearly separated sources:

- `synthetic/` — generated by the development dataset generator. Used to build the
  pipeline, never to claim accuracy.
- `real/` — deployment outcomes harvested from actual CloudForge pipeline runs.

Model metrics reported from synthetic data are a smoke test of the plumbing, not a
measure of real-world performance. Any accuracy figure must state which dataset
produced it.
